# Command: Launch Token (/project:launch-token)
Description: Panduan langkah demi langkah meluncurkan token di platform Bags.

## Instructions
1. Verifikasi metadata token (name, symbol, uri).
2. Periksa kesiapan Locked Supply Vault sesuai `.claude/rules/anti-rug.md`.
3. Jalankan simulasi pembuatan pool di devnet jika tersedia.
4. Berikan checklist konfirmasi sebelum eksekusi mainnet.
