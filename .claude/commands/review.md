# Command: Review (/project:review)
Description: Melakukan code review dengan gaya PAO (Professional, Auditable, Optimized).

## Instructions
1. Periksa kesesuaian kode dengan `.claude/rules/code-style.md`.
2. Fokus pada efisiensi Solana Compute Units jika mereview program Rust.
3. Pastikan tidak ada "Security Smells" sesuai `.claude/rules/security.md`.
4. Berikan saran optimasi performa dan keterbacaan.
5. Gunakan format tabel untuk merangkum temuan (Critical, Warning, Info).
