# Skill: Content Gen Review
Description: Mereview output konten sebelum diposting ke sosial.

## Workflow
1. Ambil drafted content dari LLM.
2. Periksa kesesuaian tone dengan persona agent.
3. Pastikan tidak ada link phishing atau bahasa kasar.
4. Minta approval user jika tingkat kepercayaan < 0.9.
