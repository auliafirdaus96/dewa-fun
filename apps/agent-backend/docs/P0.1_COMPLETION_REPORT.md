## 🚀 USAGE EXAMPLES

### **1. Authenticate Wallet**

```typescript
// Frontend code example
import { useWallet } from '@solana/wallet-adapter-react';
import nacl from 'tweetnacl';

const wallet = useWallet();

// Step 1: Get challenge
const challengeRes = await fetch('/api/auth/challenge?wallet=' + wallet.publicKey);
const { data: { nonce, message } } = await challengeRes.json();

// Step 2: Sign message
const signedMessage = await wallet.signMessage(new TextEncoder().encode(message));
const signature = Buffer.from(signedMessage).toString('base64');

// Step 3: Verify and get JWT
const verifyRes = await fetch('/api/auth/verify', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ wallet: wallet.publicKey.toString(), signature, message })
});
const { data: { token } } = await verifyRes.json();

// Step 4: Use token for authenticated requests
const agentsRes = await fetch('/api/agents/run', {
  method: 'POST',
  headers: { 
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ node_id: 'my-node', persona: 'assistant' })
});
```
