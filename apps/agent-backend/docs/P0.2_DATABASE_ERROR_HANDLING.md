### **2. Transaction Pattern dengan Rollback**

```typescript
await executeTransaction(supabase, [
  {
    name: 'insert_parent',
    execute: async (client) => {
      const { error } = await client.from('parent').insert(data);
      if (error) throw error;
      return { id: 123 };
    },
  },
  {
    name: 'insert_child',
    execute: async (client) => {
      const { error } = await client.from('child').insert(data);
      if (error) throw error;
      return { success: true };
    },
    // Optional rollback function
    rollback: async (result, client) => {
      // Clean up parent if child insert fails
      await client.from('parent').delete().eq('id', result.id);
    },
  },
]);
```

**Features:**
- ✅ Sequential step execution
- ✅ Automatic rollback dalam reverse order
- ✅ Rollback error tracking dan reporting
- ✅ Detailed logging untuk setiap step
- ✅ Support untuk async operations

## 🛡️ ERROR HANDLING BEST PRACTICES

### **Do's:**
- ✅ Always wrap database operations dengan try-catch
- ✅ Use custom error classes untuk context preservation
- ✅ Implement retry untuk transient failures (network timeouts, etc.)
- ✅ Add rollback logic untuk multi-step operations
- ✅ Log errors dengan sufficient context untuk debugging
- ✅ Validate inputs SEBELUM database operation
- ✅ Sanitize data untuk prevent insertion anomalies

### **Don'ts:**
- ❌ Never silently catch and ignore database errors
- ❌ Don't retry on constraint violations (unique, foreign key)
- ❌ Avoid retrying without exponential backoff
- ❌ Never skip rollback when partial state is dangerous
- ❌ Don't log sensitive data (passwords, private keys)
- ❌ Never throw generic Error objects (use custom errors)
