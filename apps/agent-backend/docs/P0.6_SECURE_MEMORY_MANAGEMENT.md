## 🔧 CORE FEATURES

### **1. Secure Zeroing** 🔒

**Problem**: JavaScript strings are immutable - can't actually zero them!

**Solution**: Multi-layer approach

```typescript
// For Buffers/Uint8Array
export function secureZero(buffer: Uint8Array): void {
  if (!buffer || buffer.length === 0) return;
  
  // Step 1: Fill with random bytes (more secure than zeros)
  const randomData = randomBytes(buffer.length);
  for (let i = 0; i < buffer.length; i++) {
    buffer[i] = randomData[i];
  }
  
  // Step 2: Zero out completely
  buffer.fill(0);
}

// For Strings (best effort)
export function secureZeroString(str: string): void {
  if (!str) return;
  
  // Convert to buffer and zero
  // Note: Doesn't modify original (JS immutability)
  // But prevents accidental logging/exposure
  const buffer = Buffer.from(str, 'utf-8');
  secureZero(buffer);
}
```

**Why Random → Zero?**
- Single pass zeroing can leave residual charge
- Random pattern more thoroughly scrambles bits
- Defense-in-depth against sophisticated attacks

### **2. Secure Container Pattern** 📦

```typescript
interface SecureContainer<T> {
  data: T;                    // The actual secret
  expiresAt: number | null;   // Auto-expiry timestamp
  zeroOnRead: boolean;        // Destroy after first read?
  accessedCount: number;      // How many times accessed
  maxAccessCount?: number;    // Optional limit
}
```

**Container Lifecycle:**
```
Created ──[Store]──> Active ──[Retrieve]──> Zeroed/Destroyed
                      │                        ↑
                      └──[TTL Expire]─────────┘
                      └──[Max Access]─────────┘
```

**Usage Example:**

**Cleanup Process:**
```typescript
private cleanup(): void {
  const now = Date.now();
  let cleanedCount = 0;

  for (const [key, container] of secureStore.entries()) {
    if (container.expiresAt && now > container.expiresAt) {
      this.destroy(key);  // Securely zeroes before deletion
      cleanedCount++;
    }
  }

  if (cleanedCount > 0) {
    console.log(`[SecureMemory] Cleaned up ${cleanedCount} expired entries`);
  }
}

// Auto-start cleanup interval
constructor(config: SecureMemoryConfig = {}) {
  this.config = { ...defaults, ...config };
  
  if (this.config.autoCleanup && !cleanupInterval) {
    this.startCleanup(); // Runs every 60 seconds
  }
  
  // Register exit handlers
  process.on('exit', () => this.clear());
  process.on('SIGINT', () => this.clear());
  process.on('SIGTERM', () => this.clear());
}
```

**Benefits:**

### **4. Access Control** 🚫

**Access Limiting:**
```typescript
retrieve<T>(key: string): T | null {
  const container = secureStore.get(key);
  
  if (!container) return null;
  
  // Check expiration
  if (Date.now() > container.expiresAt) {
    this.destroy(key);
    return null;
  }
  
  // Check access count
  container.accessedCount++;
  if (container.maxAccessCount && 
      container.accessedCount > container.maxAccessCount) {
    console.warn(`[SecureMemory] Max access exceeded for: ${key}`);
    this.destroy(key);
    return null;
  }
  
  return cloneAndSecureZero(container.data);
}
```

**Example:**

### **5. withData Pattern (Recommended)** 🎯

**Safe Usage Pattern:**
```typescript
withData<T, R>(key: string, callback: (data: T) => R): R | null {
  const data = this.retrieve<T>(key);
  
  if (data === null) return null;

  try {
    const result = callback(data);
    
    // Automatically destroy after use
    if (this.config.zeroAfterUse) {
      this.destroy(key);
    }
    
    return result;
  } catch (error) {
    console.error(`[SecureMemory] Error in callback:`, error);
    this.destroy(key);
    throw error;
  }
}
```
