## 🔧 CORE FEATURES

### **1. Sliding Window Rate Limiting** ⏱️

**Algorithm:**
```typescript
interface RateLimitInfo {
  count: number;        // Current request count
  resetTime: number;    // When window resets
  remaining: number;    // Requests left
  lastAccess: number;   // Last request time
}
```

**How It Works:**
```
Request 1 (t=0s):   count=1, remaining=4 ✅
Request 2 (t=10s):  count=2, remaining=3 ✅
Request 3 (t=20s):  count=3, remaining=2 ✅
Request 4 (t=30s):  count=4, remaining=1 ✅
Request 5 (t=40s):  count=5, remaining=0 ✅
Request 6 (t=50s):  BLOCKED! ❌ (Retry after 10s)
Request 7 (t=70s):  Window reset, count=1 ✅
```
