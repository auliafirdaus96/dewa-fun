### **2. Price Aggregation Engine** 🔄

**Aggregation Algorithm:**
```typescript
async function getAggregatedPrice(
  symbol: string,
  connection?: Connection
): Promise<AggregatedPrice | null> {
  // Fetch from both oracles in parallel
  const [pythPrice, chainlinkPrice] = await Promise.all([
    fetchPythPrice(symbol),
    fetchChainlinkPrice(symbol, connection),
  ]);
  
  // Handle failures gracefully
  if (!pythPrice && !chainlinkPrice) {
    // Use cache as last resort
    return getCachedPrice(symbol);
  }
  
  // Single oracle working
  if (!pythPrice && chainlinkPrice) {
    return {
      symbol,
      price: chainlinkPrice.price,
      confidence: chainlinkPrice.confidence,
      isReliable: true,
    };
  }
  
  // Both working - aggregate with weighted average
  if (pythPrice && chainlinkPrice) {
    const deviation = calculateDeviation(
      pythPrice.price,
      chainlinkPrice.price
    );
    
    // Weighted average (Chainlink slightly preferred)
    const weights = {
      pyth: 0.45,
      chainlink: 0.55,
    };
    
    const aggregatedPrice = 
      pythPrice.price * weights.pyth + 
      chainlinkPrice.price * weights.chainlink;
    
    return {
      symbol,
      price: aggregatedPrice,
      confidence: weightedConfidence,
      chainlinkPrice: chainlinkPrice.price,
      pythPrice: pythPrice.price,
      deviation,
      isReliable: deviation < 5%, // Reliable if <5% deviation
    };
  }
}
```

### **3. Intelligent Caching** ⚡

**Cache Structure:**
```typescript
class PriceCache {
  private cache: Map<string, CachedPrice> = new Map();
  private readonly maxAgeMs: number = 60 * 1000; // 1 minute
  
  set(symbol: string, price: CachedPrice): void {
    this.cache.set(symbol, {
      price,
      timestamp: Date.now(),
      confidence,
      source: 'pyth' | 'chainlink',
    });
  }
  
  get(symbol: string): CachedPrice | null {
    const cached = this.cache.get(symbol);
    
    if (!cached) return null;
    
    // Auto-expire stale data
    if (Date.now() - cached.timestamp > this.maxAgeMs) {
      this.cache.delete(symbol);
      return null;
    }
    
    return cached;
  }
}
```

**Cache Benefits:**
- ✅ Fast responses (< 1ms vs ~50ms network call)
- ✅ Reduced API rate limits
- ✅ Graceful degradation during outages
- ✅ Automatic expiry prevents stale data

### **4. Deviation Detection** 📏

**Detection Algorithm:**
```typescript
function calculateDeviation(price1: number, price2: number): number {
  const avg = (price1 + price2) / 2;
  if (avg === 0) return 0;
  
  return Math.abs((price1 - price2) / avg) * 100;
}

// Example:
// Pyth: $100
// Chainlink: $105
// Deviation: |(100 - 105) / 102.5| * 100 = 4.88%

if (deviation > threshold) {
```

## 🛡️ FAULT TOLERANCE

### **Multi-Layer Fallback Strategy:**

```
┌─────────────────────────────────────────┐
│  Layer 1: Check Cache (< 1 min old)     │ ← Fastest (~1ms)
└──────────────┬──────────────────────────┘
               │ Hit
               ▼
         Return cached price
               │
               │ Miss
               ▼
┌─────────────────────────────────────────┐
│  Layer 2: Fetch from Both Oracles       │ ← Preferred (~50ms)
│  - Pyth Network                         │
│  - Chainlink                            │
└──────────────┬──────────────────────────┘
               │ Both succeed
               ▼
         Aggregate & return
               │
               │ One fails
               ▼
┌─────────────────────────────────────────┐
│  Layer 3: Use Working Oracle            │ ← Fallback (~50ms)
│  - Return single source price           │
└──────────────┬──────────────────────────┘
               │
               │ Both fail
               ▼
┌─────────────────────────────────────────┐
│  Layer 4: Use Stale Cache               │ ← Last resort (< 1ms)
│  - Return old price with warning        │
│  - Mark as unreliable                   │
└──────────────┬──────────────────────────┘
               │
               │ No cache
               ▼
         Throw error
```

**Reliability Math:**
```
Assuming:
- Pyth uptime: 99.9%
- Chainlink uptime: 99.9%
- Independent failures

Probability both fail simultaneously:
P(both down) = P(Pyth down) × P(Chainlink down)
             = 0.1% × 0.1%
             = 0.0001 = 0.01%

System uptime = 100% - 0.01% = 99.99%

With cache layer: ~99.999% (effectively always available)
```
