## ⚙️ **CONFIGURATION GUIDE**

### Set via Frontend Dashboard:
1. Go to Agent Settings → Social Configuration
2. Choose preset template OR write custom
3. Adjust frequency (1-10 posts/day)
4. Select platforms (Twitter, Telegram)
5. Toggle enabled/disabled
6. Save and watch AI work!

### API Example:
```python
POST /api/agents/{agent_id}/social-config
{
  "persona_prompt": "...",
  "frequency": 5,
  "tone": "witty",
  "platforms": ["twitter", "telegram"],
  "enabled": true
}
```

## 📊 **BEST PRACTICES**

### Do's ✅:
- Start with lower frequency (2-3/day) and scale up
- Monitor engagement metrics weekly
- A/B test different personas monthly
- Keep persona consistent with brand identity
- Update persona based on community feedback

### Don'ts ❌:
- Don't post more than 10x/day (spam risk)
- Don't change persona too frequently
- Don't ignore negative engagement
- Don't use for financial advice/shilling
- Don't enable without Twitter API keys configured
