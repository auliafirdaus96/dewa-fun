# 🛠️ AI Agent & Utility Deep Dive

Agent "Dewa" dirancang dengan kemampuan untuk mengelola platform secara otonom.

## 🔋 Fitur Utama AI
- **Social Content Factory**: Men-generate narasi promosi viral (Twitter/Telegram) menggunakan data real-time blockchain untuk partner.
- **DLMM Optimization**: Memantau volume dan likuiditas pool Meteora untuk menjaga kesehatan ekonomi token secara otonom.
- **Governance Action**: Mengeksekusi Buyback & Burn otonom untuk meningkatkan nilai token protokol.
- **Casino Promotion**: Melakukan promosi game kasino dinamis saat volume trading sedang rendah.
- **Badge Minting**: Secara otomatis mencetak NFT pencapaian Metaplex bagi pengguna loyal.

## 🧩 Modul SDK (Packages)
- **`@dewa/shared-types`**: Definisi metadata agen, posisi DLMM, dan schema badge.
- **`@dewa/solana-utils`**: Helper function untuk berinteraksi dengan kontrak Dewa dan pool Meteora.
